# design-team-hub

IMC 3본부 디자인팀 업무 허브.
팀이 지금 어떻게 돌아가는지를 한 화면에서 관리합니다.


## 기술

React · Vite · Vercel 배포.
데이터는 Google Apps Script를 통해 스케줄 시트 + 구글 캘린더와 연결.

위젯([design-widget-schedule](https://github.com/Peekaboo325/design-widget-schedule))이
개인 디자이너의 "배정 업무"를 담당한다면, 허브는 팀 전체가 "어떻게 돌아가는지"를 담당합니다.
